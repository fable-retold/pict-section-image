Image Viewer
pict-section-image

Four standalone pict-section-image viewers, each with its own Fit / zoom-in / zoom-out / download toolbar. Every image fits the stage by default; zoom is a multiplier of the fit size, so above 1× the stage scrolls and you can pan — or just click an image to toggle fit ↔ zoomed. The wide panorama is the one to zoom into. This is the same class pict-section-fileview mounts as its image lens; here it runs on its own.
